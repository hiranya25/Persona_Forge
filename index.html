The problem

Generic AI agents weren't built for diligence.

A screening or diligence agent that quietly drifts outside its mandate isn't a UX flaw — for a firm that has to answer for every judgment it puts in front of an LP, a regulator, or opposing counsel, it's a liability. Most teams find out an agent went off-script after the fact, from a transcript, not before.

RISK
An agent answers outside its defined scope, with no flag and no record.
RISK
No trail linking a given output back to the rule set that should have governed it.
The concept

One persona-locked agent. Five components that keep it honest.

Persona Forge runs on a self-hosted, open-weight model. A software layer wraps every agent built on it with a defined persona, continuous verification, and a permanent audit trail.

01
Persona Wrapper
Tone, scope, forbidden topics, and escalation rules — defined once, versioned, and enforced on every response.
02
Preset Agents
Deal-screening and diligence agents pre-built for the vertical, so a firm isn't starting from a blank prompt.
03
Agent-Creation UI
Authorized users assemble new agents from a persona, tools, and a task — no code, gated by license tier.
04
Controls & Audit
Every output verified before it's returned; flagged items routed to review; an immutable audit trail behind it all.
05
Backend Build-Out & Analytics
We stand up and operate the inference backend, sized to the model class a deployment needs, with usage visible in real time.
ARCHITECTURE
Multi-tenant, role-based, and audited from the first line of code — not features bolted on after a pilot.
How it works

Every response passes through the same four checkpoints.

STEP 1
Query arrives
A user or system sends a request to a persona-locked agent.
STEP 2
Agent responds within persona
The model generates a response constrained by the active persona spec.
STEP 3
Verified before delivery
A fast check runs on every output; low-confidence cases escalate to a thorough review.
STEP 4
Logged to the audit trail
Every output is linked to the persona version and rule outcome that governed it — permanently.
Multi-tenant from day one
Isolated data per client, not retrofitted after pilot.
Role-based access + MFA
Enforced at the API layer, not just the UI.
Full audit trail per output
Every response traceable to its persona version and rule outcome.
On-prem option
For deal data that can't leave your own environment.
